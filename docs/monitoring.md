# Monitoring

Part of the IACP production hardening layer. Additional modules:
- Security: identity, authentication, authorization, policies
- Encryption: AES-256-GCM, signing, hashing
- Rate Limiting: token bucket, sliding window
- Resilience: circuit breaker, bulkhead, retry, health checks
- Observability: logging, tracing, metrics export (Prometheus)
- Monitoring: runtime, queue, transport, health aggregation
- Fault Injection: simulated failures for testing
- Config: profiles, env vars, validation
- Recovery: backup, restore, queue recovery
